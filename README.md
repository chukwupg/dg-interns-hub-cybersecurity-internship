## What I've covered so far
- **Week 1:** VirtualBox home lab (Kali, Ubuntu, Windows), Linux administration and permissions, networking foundations, OverTheWire Bandit 0 to 10, 8 TryHackMe rooms.
- **Week 2:** Read TCP handshakes and Nmap scans in Wireshark, and traced Windows logons, account changes and log clearing in Event Viewer and PowerShell, all in an isolated lab.
- **Week 3:** Endpoint telemetry with Sysmon (Windows) and auditd (Linux), and Snort 3 rules mapped to MITRE ATT&CK T1046.
- **Week 4:** Built a working SIEM pipeline in Splunk (log ingestion, SPL detections, scheduled alerts, dashboarding) and documented Wazuh architecture and a custom correlation rule.
- **Week 5:** phishing header analysis, sandbox report reading, ATT&CK Navigator mapping, Atomic Red Team detection testing and incident reporting
